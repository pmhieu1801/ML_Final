# Final Submission Checklist

## Mandatory Files
- [ ] report.pdf
- [ ] notebook.ipynb
- [ ] predictions.csv

## Strongly Recommended Files
- [ ] README.md
- [ ] requirements.txt

## Rubric Coverage Check
- [ ] Problem statement and dataset scope are clearly described.
- [ ] EDA includes dataset structure, feature types, target distribution, and key visualizations.
- [ ] Preprocessing decisions are justified and leakage avoidance is explained.
- [ ] At least 3 models are trained and compared (current notebook has 4).
- [ ] At least one meaningful improvement over midterm is explicitly stated.
- [ ] Required metrics are reported: Accuracy, Precision, Recall, F1, Confusion Matrix.
- [ ] Recommended metrics are reported: ROC-AUC, PR-AUC.
- [ ] Error analysis includes false positive/false negative patterns and grouped analysis.
- [ ] Model interpretation is included (coefficients and/or feature importance).
- [ ] Final recommendation is justified by performance, stability, interpretability, and practicality.

## Report Quality Check
- [ ] Report is written in English.
- [ ] Report length is >= 15 pages (target 20-25 pages for safety).
- [ ] Every figure/table has a caption and is explained in text.
- [ ] Methods section explains why decisions were made, not only what was done.
- [ ] No large raw code dumps or screenshot-only sections.

## Reproducibility Check
- [ ] Notebook runs from top to bottom without manual edits.
- [ ] Random seeds are fixed where relevant.
- [ ] Package versions are documented.
- [ ] Output tables in report match notebook outputs.

## Final Sanity Check Before Upload
- [ ] File names follow required conventions.
- [ ] Team contribution statement is included in report.
- [ ] All claims in report are supported by results.
- [ ] No data leakage or inconsistent methodology statements.
